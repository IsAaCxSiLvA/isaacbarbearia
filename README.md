# Isaacbarbearia

Site/app para uma barbearia, com interface web e estrutura para paginas, servicos e publicacao.

## Visao geral

Este repositorio faz parte dos projetos da conta **snep-isc**. A ideia e manter o codigo organizado, documentado e facil de continuar evoluindo.

## Funcionalidades

- Interface web para apresentar a barbearia
- Paginas e componentes para organizacao dos servicos
- Estrutura pronta para evoluir com login, conteudo e deploy

## Tecnologias

- HTML
- CSS
- JavaScript
- TypeScript
- Angular / Vite
- Firebase

## Como usar

Clone o repositorio:

``bash
git clone https://github.com/snep-isc/isaacbarbearia.git
cd isaacbarbearia
``

Comandos ou passos principais:

- `npm install`
- `npm run dev`

## Estrutura

A estrutura pode mudar conforme o projeto evolui. Consulte os arquivos e pastas do repositorio para entender a organizacao atual.
